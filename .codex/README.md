# Orientación Codex para AppleAppLab

Este directorio contiene contexto operativo exclusivo para Codex dentro de este repositorio.

## Orden de lectura

1. `AGENTS.md` — contrato principal y límites.
2. Petición actual del usuario — alcance y autorización.
3. Documentos existentes del proyecto — evidencia local.
4. `.codex/roles.md` — contratos de los agentes.
5. `.codex/skill-routing.md` — selección de skills.
6. La skill especializada aplicable — procedimiento detallado.

Estos archivos no son instrucciones para Claude, Cursor ni Gemini. No deben provocar cambios en `.claude/**`, `.cursor/**`, `CLAUDE.md` o `GEMINI.md`.

La documentación detallada de cada especialista permanece en las skills instaladas. Aquí solo se conserva el contexto necesario para enrutar tareas y hacer handoffs consistentes.
